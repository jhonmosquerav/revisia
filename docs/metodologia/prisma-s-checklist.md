## Ítems "por cada base de datos" vs. globales

Por el propio texto verbatim, aplican **por cada base de datos / fuente / estrategia** (no basta un enunciado global):

- **Ítem 1** — "Name **each individual database**…" (nombre + plataforma por base).
- **Ítem 8** — estrategia completa "**for each database and information source**, copied and pasted exactly as run".
- **Ítem 13** — fecha de última búsqueda "**for each search strategy**" (en la práctica, por base de datos).
- **Ítem 15** — total de registros "**from each database** and other information sources".

Los demás (2-7, 9-12, 14, 16) se reportan a nivel de métodos globales de la revisión, aunque 9-10 deben aclarar a qué búsquedas aplican si difieren entre bases.
